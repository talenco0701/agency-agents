差し替え方法: Xserverファイルマネージャで既存 index.html を本ファイルに置き換え

## 1. 不具合の修正（先に直したもの）

### ① 予約フォームの日程が「過去日付」になっていた ★実害あり
選択肢8件のうち **5件（7/9・7/16・7/23・7/30・8/6）が既に過去日**でした。
8/27を過ぎると **選択できる日程がゼロ**になり、予約が完全に不可能になる状態でした。

→ 個別説明会・随時日程調整の運用に合わせ、後述の「曜日＋時間帯」方式に変更。
　 **今後、日付の手動更新は不要**です。

### ② CSSアニメーション3種が破損していた
`@keyframes` の `@` が不正なバイト（NUL）に化けており、以下が無効化されていました。

| 壊れていたアニメーション | 影響 |
|---|---|
| `fade-up` | ヒーロー部分のフェードイン演出が効かない |
| `pulse-glow` | 光る演出が効かない |
| `spin-slow` | 配管アイコンの回転が効かない |

→ 3箇所とも復元済み。表示崩れではなく演出が無効化されていただけですが、意図通りに戻しました。

※ スクロール連動の表示（`.reveal`）は**正常に動作**していました。こちらは問題ありません。

## 2. 個別説明会・随時日程調整への対応

「毎週木曜18:00/18:30/19:00 固定」の前提で書かれていた箇所を全て書き換えました。

| 箇所 | 変更前 | 変更後 |
|---|---|---|
| ページタイトル / meta | 毎週木曜開催 | オンライン個別説明会（日程はご都合に合わせて調整） |
| ヒーローのDATE | 毎週 木曜日 | 随時 受付中 ／ ご都合に合わせて調整します |
| ヒーローのTIME | 18:00 / 18:30 / 19:00 | 平日夜18:00〜／日中も可・1対1の個別開催 |
| 開催概要 | 毎週木曜日・前日までに要予約 | 随時（個別に日程調整）・ご予約後に担当者が希望を伺う |
| フォーム下部 | 前日17:00までに予約 | 履歴書不要・日程は後から調整OK |

### 予約フォームの項目変更

| 変更前 | 変更後 |
|---|---|
| 希望日程（木曜日から選択・固定8件） | **ご希望の曜日**（平日／土曜／日曜・祝日／いつでも可） |
| 希望時間帯（18:00・18:30・19:00） | **ご希望の時間帯**（18:00〜/18:30〜/19:00〜/19:30〜/日中/相談したい） |
| — | **具体的なご希望日時・聞きたいこと**（任意・自由記述）を新設 |

- 送信先GASの項目名 `name` / `email` / `date` / `time` は**そのまま維持**しているため、
  既存のスプレッドシート・通知メールはこれまで通り動作します。
- 新設した自由記述欄は `note` という項目名で送信されます。
  **通知メールにも表示したい場合**は、GAS（`reserve-backend.gs`）の `notify_` 関数の本文に
  次の1行を追加してください:
  ```js
  "ご要望　：" + (d.note || "") + "\n" +
  ```

## 4. 追加した透明性コンテンツ

総括レポートの課題②「未経験・20/30代に対する情報の透明性不足」への対応です。
**内容はすべて社員インタビューと既存の募集要項から取っており、新たな取材なしで公開できます。**

### ① 仕事の1日（働き方の透明性）
8:00出社 → 8:30現場 → 午前作業 → 12:00休憩 → 15:00仕上げ → **17:00退社** のタイムライン。
「社長も部長も定時で帰る＝帰りにくい空気がない」を明記。
休日欄で **第1・第3土曜が出勤である旨も隠さず記載**。

### ② 未経験からの成長ステップ（業務内容の透明性）
入社〜数ヶ月（穴掘り・資材運び）→ 半年〜1年（簡単な配管＋資格勉強）→ 2〜3年（一通り回せる）
→ 5年〜（専門を持ち教える側）の4ステップ。資格費用全額負担・試験日も出勤扱いを明記。

### ③ 働く人（共感）
社員2名の声を掲載。
- 営業業務部（勤続約20年）「前職は残業月100時間超でも給料は今と同じ。今は基本17時に帰れる」
- 配管歴16年・管理担当「未経験でも大丈夫。最初は先輩について回って覚える」
職場の雰囲気（さん付け文化・怒鳴る親方はいない）も記載。

### ④ 正直に言うと、大変なこともあります（両面開示）
公開調査で「応募を続けたい状態の第1位＝良い面・悪い面の両方が見える（73.6%）」
「過度なキラキラ感が離脱要因（44.2%）」と出ているため、**大変な点と会社の対応をセット**で掲載。

| 大変な点 | 会社がやっていること |
|---|---|
| 屋外の仕事。夏は暑く冬は寒い | 制服・安全防具貸与、「怪我なく帰る」「暗くなる前に終える」の徹底 |
| 入って最初は穴掘りが中心 | いきなり一人にしない。熟練者に同行。研修期間中も給与保証 |
| 第1・第3土曜は出勤 | 平日は基本17時退社。日曜・第2/4/5土曜・祝日は休み |

末尾に「まずは説明会で直接聞いてください」＋CTAを配置しています。
