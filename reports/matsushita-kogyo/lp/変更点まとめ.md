# 【第4版】コンバージョン計測の是正 ★重要

## 見つかった問題

### ① CTAクリックが「コンバージョン」として計上されていた（過大計上）

計測スクリプトに、**ボタンを押しただけで `lead_submit`（＝コンバージョン）を発火する**処理が
入っていました。対象は7箇所（ヘッダー／ヒーロー／LINE／ABEMA下／最終／フッター 等）。
実際のフォーム送信成功時にも同じ `lead_submit` が飛ぶため、両者が同じ名前で混在していました。

原因はコード内のコメントに残っていました:
> ※Googleフォーム送信完了は計測できないため、ボタンクリック=Leadとして扱う

**旧Googleフォーム時代の名残**です。現在はGAS実装で送信完了を取得できるため不要でした。

**影響**: GA4/Metaのコンバージョン数が実際の予約より大幅に多くなります。
「LPの予約フォーム本番CVは0件」という実績にもかかわらずCVが立っていた場合、
その正体はボタンクリックです。Meta広告もこの信号で最適化されるため、
「押すが予約はしない層」に配信が寄っていた可能性があります。

### ② 常時表示のLINEボタンが完全に未計測だった（過少計上）

画面右下に固定表示されている「LINEで相談する」ボタンに、計測タグが**一切付いていません**でした。
LINE経由の反応は議事録でも「若手に多い」とされている導線ですが、数字に残っていませんでした。

### ③ 電話が計測できない状態だった

`076-433-2040` はテキストのみで `tel:` リンクがなく、スマホでタップ発信できませんでした。

### ④ Metaピクセルがページ上に存在しない（要確認）

`fbq(` も `connect.facebook.net` も0件です。GTM経由で入れる設計ですが、
週次観測では `landing_page_view = 0` の一方でClarityには実セッションが記録されていました。
**GTM側にピクセルが入っていない、または発火していない可能性が高い**です。
GTM管理画面での確認をお願いします（こちらからは参照できません）。

## 実施した修正

| 修正 | 内容 |
|---|---|
| CVの分離 | CTAクリック側を `lead_submit` → **`cta_lead_intent`** に改名。`lead_submit` は**予約フォームの送信成功時のみ**発火するようになりました |
| LINEの分離 | LINEクリックを **`line_click`** として別途送信。友だち追加導線を単独評価できます |
| 固定LINEボタン | 計測タグを付与（`cta_click` / label=`floating_line`） |
| 取りこぼし防止 | 送信ボタン押下時に **`form_submit_attempt`** を送信。GAS側に保存されたのに通信エラーになったケースを突合できます |
| 電話 | `tel:0764332040` のリンク化＋ **`call_click`** イベントを追加 |

### 動作確認済み（ブラウザで実行）
- ヒーローCTAクリック → `cta_click` / `cta_lead_intent` のみ（**`lead_submit` は飛ばない**）
- 固定LINEクリック → `cta_click` / `cta_lead_intent` / `line_click`
- `tel:` リンク＋`call_click` の存在を確認

## GTM側でお願いしたい設定

1. **コンバージョンを `lead_submit` に設定**（＝実際の予約フォーム送信のみ）
   - 併せて飛ぶ `form_submit_success` を使っても同じです
2. `cta_lead_intent` は**コンバージョンから外す**（中間指標として見る）
3. `line_click` / `call_click` は、必要に応じて**サブのコンバージョン**として別枠で設定
4. **Metaピクセルが実際に発火しているか確認**（④の件）
5. GA4で **`form_submit_error` / `form_submit_attempt` の件数を比較**
   - attempt が多く success が少ない → 送信処理が失敗している可能性

### ご注意
この修正により、**見かけ上のコンバージョン数は大幅に減ります**。
これは実態（フォーム送信数）に一致させた結果であり、悪化ではありません。
Meta広告の学習もリセットされるため、切り替え時期は配信状況を見てご判断ください。
