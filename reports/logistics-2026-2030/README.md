## 主な論点

2026年に制度が一斉に切り替わったことを起点に据えている。

- 取適法（旧下請法）施行（2026年1月）— 運送委託が適用対象に追加、手形払い禁止
- 総合物流施策大綱（2026年度〜2030年度）閣議決定（2026年3月31日）— 2030年度までを「集中改革期間」と位置づけ
- 改正物流効率化法 全面施行（2026年4月）— 特定荷主約3,200社にCLO選任義務、未選任は100万円以下の罰金
- 軽油引取税 暫定税率（17.1円/L）廃止（2026年4月）

これらを「規制」ではなく「荷主交渉のレバー」として使う筋立てを第2章D2および第5章5-5に置いている。

## 未了・注意点

- **レイアウトの目視確認ができていない**。この環境の LibreOffice（`soffice`）はあらゆる入力に対して "source file could not be loaded" を返し、pandoc も未インストールのため、PDF化による見た目の確認を行えていない。XMLレベルでは検証済み（段落730・表26、全表のセル幅合計が表幅と一致、見出し階層が正常）だが、印刷前に一度Wordで開いて改ページ位置と表の折り返しを確認すること。

- 将来推計・シナリオ確率・リスク評価には【推計】、民間調査由来の数値には【民間】を付記している。
